DB Browser 0.4 — bản web thử nghiệm cho GitHub Pages

Cách cập nhật: giải nén ZIP, mở thư mục DBBrowser_v04, tải index.html lên thư mục gốc repository GitHub và chọn Replace/Commit changes.

Lưu ý: GitHub Pages chỉ lưu trữ website. Google, YouTube và nhiều trang chặn iframe nên không thể buộc chúng hiển thị bên trong khung. Nút Mở ngoài mở trang bằng Safari. Bản 0.4 đổi khung nền, giảm khoảng trắng, thêm nút tải lại và hướng dẫn ngay dưới khung. Dấu trang/lịch sử/tab bản 0.3 vẫn được giữ riêng trong trình duyệt nếu còn dữ liệu dbb3; dữ liệu mới của 0.4 dùng kho riêng.
